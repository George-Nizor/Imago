# Framekit MCP

Stdio MCP server for controlling Framekit from Cursor or other MCP clients.

## Tools

- `open_framekit` — start UI + open browser
- `create_youtube_thumbnail` — headless 1280×720 export
- `create_title_card` — transparent PNG
- `remove_background` — local cutout
- `list_background_variants`
- `get_brand_kit` / `update_brand_kit`
- `open_export`

## Run manually

```bash
npm install
npm start
```

Configured for Cursor via the repo root `.cursor/mcp.json`.
