## Series style

This project is one episode in the series "{{name}}". The owner wants every episode to look like it
belongs to the same channel, while each one is clearly its own. A reference is in this folder:

- `assets/style-reference.png` is the render of an earlier episode. Read it to see the look.
- `reference/style-reference.html` is the HTML of that episode. Read it to copy the exact layout
  system, type, colours, badges and treatment.

Read both before you design. Then match the reference exactly in everything that makes the series
recognisable: the layout system and where each element sits, the typefaces, sizes and weights, the
colour palette and gradients, the badges, strokes, shadows, outlines and other treatments, the
spacing and the way the subject is cut out and placed. Start from the reference's HTML and keep its
structure and styles; do not invent a new look.

Change only the content: the title words and the imagery (the subject, the photo or the picture).
The result must be unmistakably the same channel and still its own episode, so it should not be a
copy of the reference.

The reference files are for looking at only. Never use `assets/style-reference.png` as an image in
the design, never copy its subject or headline, and never edit the reference files.
