# Thumbnail craft: start here

These files are your reference for thumbnails and vertical covers. They are read-only; read only
what the job needs. Always read the first two. Then read the file for your format and your archetype.

| File | Read it when |
| --- | --- |
| `honesty-and-title.md` | Always. What may appear on the image, and how the image and the title share the work |
| `face-finishing.md` | The image has a person or a cut-out subject; also how to use the owner's face pack (`find_faces`, `use_face`, grades, mirroring) |
| `archetypes/<id>.md` | Always one: your archetype. Ids: `reaction`, `result-reveal`, `before-after`, `versus`, `number`, `curiosity-gap`, `object-hero`, `story-moment` |
| `vertical.md` | The format is Shorts 9:16 (YouTube Shorts, Instagram Reels, TikTok) |
| `square.md` | The format is podcast 1:1 |
| `judging.md` | Before your first render, so you know what the checks and the feed mock-up will tell you |
| `kit.md` | The first message has a "From the video" section (frames, hooks, palette, fonts, pictures) |

If the owner or a concept already names an archetype, use it. If neither does, pick the one whose
"Fits when" matches the brief best and say which in your reply. Do not blend two archetypes: a
thumbnail with two ideas has none.
